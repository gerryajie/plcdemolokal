# MonitorPLC Desktop Build Guide

Guide lengkap untuk membangun aplikasi desktop MonitorPLC untuk Windows dan Linux.

## Prasyarat

Pastikan Anda sudah install:
- Node.js 16+
- npm atau yarn
- Git

### Untuk Windows
- Windows 7 atau lebih baru
- Visual C++ Redistributable

### Untuk Linux
- Ubuntu 18.04+ / Debian 10+
- Build tools: `build-essential`, `libssl-dev`, `pkg-config`

Instalasi dependencies di Linux:
```bash
sudo apt-get install build-essential libssl-dev pkg-config
```

## Setup Awal

### 1. Install Dependencies

```bash
# Install dependencies di root project
npm install

# Install dependencies Backend
cd BE
npm install
cd ..

# Install dependencies Frontend
cd FE
npm install
cd ..
```

### 2. Setup Environment Variables

Pastikan `.env` sudah dikonfigurasi di direktori `BE/`:

```bash
# BE/.env
PORT=5000
DATABASE_HOST=localhost
DATABASE_USER=root
DATABASE_PASSWORD=password
DATABASE_NAME=monitorplc
NODE_ENV=production
```

## Development

### Mode Development (Windows & Linux)

```bash
cd FE
npm run electron-dev
```

Ini akan:
- Menjalankan Vite dev server di port 5173
- Menjalankan Backend Node.js di port 5000
- Membuka Electron app yang connect ke dev server

## Build untuk Production

### 1. Build Frontend

```bash
cd FE
npm run build
```

Ini menghasilkan folder `FE/dist` dengan bundled React app.

### 2. Siapkan Backend Runtime

Script build Windows dan Linux akan otomatis menyalin runtime Node.js ke `FE/build-runtime/` sebelum packaging. Ini membuat backend bisa berjalan di komputer target tanpa perlu install Node.js secara manual.

```bash
# Windows
build-desktop-windows.bat

# Linux
chmod +x build-desktop-linux.sh
./build-desktop-linux.sh
```

### 3. Build Desktop App

#### Build untuk Windows (NSIS Installer + Portable)

```bash
cd FE
npm run electron-build:win
```

Output akan tersimpan di `FE/release/`:
- `MonitorPLC-1.0.0.exe` - NSIS Installer
- `MonitorPLC-1.0.0-portable.exe` - Portable version

Untuk target spesifik:

```bash
cd FE
npm run electron-build:win:nsis
npm run electron-build:win:portable
```

#### Build untuk Linux (AppImage + DEB)

Build Linux harus dijalankan dari Linux native atau WSL2. Jangan memakai output Linux yang dibuat dari Windows jika backend memakai native dependency seperti `node-snap7`, karena binary native dan runtime Node.js harus cocok dengan Linux.

**Cara recommended di Linux:**

```bash
chmod +x build-desktop-linux.sh
./build-desktop-linux.sh
```

Pilih opsi `4. Build Both Linux Installers`.

**Cara manual di Linux:**

```bash
cd FE
mkdir -p build-runtime
cp "$(command -v node)" build-runtime/node
chmod +x build-runtime/node
npm run electron-build:linux
```

Output akan tersimpan di `FE/release/`:
- `MonitorPLC-1.0.0.AppImage` - AppImage (portable)
- `monitorplc_1.0.0_amd64.deb` - Debian package

Untuk target spesifik:

```bash
cd FE
npm run electron-build:linux:appimage
npm run electron-build:linux:deb
```

**Di Windows (cross-build untuk Linux):**
```bash
cd FE
npm run electron-build -- --linux --publish=never
```

**Catatan:** Cross-building dari Windows ke Linux memiliki keterbatasan, terutama untuk package `.deb`, native dependencies, permission file executable, dan runtime backend. Disarankan build Linux di Linux native atau WSL2.

#### Build untuk Semua Platform

```bash
cd FE
npm run electron-build
```

Akan membuat installer untuk platform yang Anda gunakan.

## Distribusi

### Windows Distribution

1. **NSIS Installer** (Recommended)
   - User-friendly installer with uninstall support
   - File: `MonitorPLC-1.0.0.exe`
   - Size: ~200-300MB

2. **Portable Version**
   - No installation required
   - File: `MonitorPLC-1.0.0-portable.exe`
   - Size: ~200-300MB

### Linux Distribution

1. **AppImage** (Recommended untuk Desktop Users)
   - Universal format, works on most distributions
   - File: `MonitorPLC-1.0.0.AppImage`
   - Installation: Cukup beri izin executable dan jalankan
   
   ```bash
   chmod +x MonitorPLC-1.0.0.AppImage
   ./MonitorPLC-1.0.0.AppImage
   ```

2. **DEB Package** (Untuk Ubuntu/Debian)
   - Installation: `sudo apt install ./monitorplc_1.0.0_amd64.deb`
   - Akan terintegrasi dengan system menu

## File Structure untuk Build

```
FE/
|-- public/
|   |-- electron.cjs           # Main Electron process
|   |-- preload.cjs            # Preload script
|   `-- icon.png               # App icon, optional
|-- src/                       # React app source
|-- dist/                      # Built React app, generated
|-- build-runtime/             # Node.js runtime, generated by build script
|-- release/                   # Final installers, generated
|-- electron-builder.json      # Build configuration
`-- package.json
```

## Troubleshooting

### Backend tidak mau start

```bash
# Check logs
cat ~/.config/MonitorPLC/logs/main.log    # Linux
# atau
%APPDATA%\MonitorPLC\logs\main.log        # Windows
```

### Port sudah terpakai

Backend default menggunakan port 5000. Jika sudah terpakai:

```bash
# BE/.env
PORT=5001
```

### Icon tidak muncul

Pastikan icon sudah ada di `FE/public/icon.png` (512x512 PNG recommended).

### Build gagal di Linux

Pastikan package requirements sudah install:
```bash
sudo apt-get install libssl-dev pkg-config
```

Jika membuat AppImage di Linux baru dan muncul error FUSE, jalankan:

```bash
sudo apt-get install libfuse2
```

### App tidak mau connect ke Backend

Check:
1. Backend process running (check logs)
2. Port 5000 accessible
3. Firewall tidak memblokir port

## Versioning

Update versi di `FE/package.json` sebelum build:

```json
{
  "version": "1.0.1"
}
```

Version ini akan digunakan di nama file installer dan DEB package.

## Performance Tips

1. **Development Build**
   - Disable DevTools di production (lihat `electron.cjs`)
   - Optimize bundle size dengan webpack analyzer

2. **Production Build**
   - Gunakan `NODE_ENV=production`
   - Enable code splitting
   - Compress assets

3. **Backend Optimization**
   - Gunakan PM2 jika ada (optional)
   - Monitor memory usage
   - Enable caching di database queries

## Security Recommendations

1. **Code Signing** (untuk distribution)
   ```bash
   # Windows: Gunakan code signing certificate
   # Linux: Sign DEB package
   ```

2. **Update Mechanism**
   - Implementasi auto-update dengan electron-updater
   - Host release notes di server

3. **Sensitive Data**
   - Store credentials di system keychain
   - Encrypt local data
